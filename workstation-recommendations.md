# Workstation Suitability Assessment
    Meridian has three different employee profiles;

## Employee A(Finance Oficer)
REgularly uses: 
- Excel
- Outlook
- Browser applications
- Teams;
- PDF document
- Accounting software
 
This type of work does not require an extremely powerful workstation, but the computer should be capable of running several business applications at the same time.

CPU: A modern processor with at least 4 cores would be suitable. The CPU is responsible for processing and executing instructions and allows the employee's applications and operating system to run.

RAM: 8 GB minimum, with 16 GB being preferable. RAM temporarily holds the applications and data currently being used. Since the employee may have Excel, Outlook, Teams, browser tabs, and accounting software open at the same time, 4 GB would be limiting.

Storage: 256-512 GB SSD. The SSD provides permanent storage for the operating system, applications, documents, and other files. An SSD would also provide faster performance than HDD.

Network Capability: Reliable Wi-Fi capability should be provided. The employee may use the organisations wireless network's, while a smartphone hotspot could be used as a temporary alternative if necessary. A stable internet connection is important for Teams, Outlook, browser applications, and other online services.

Operating System: Windows 10/11 Pro would be suitable because it supports common business applications such as Microsoft 365, accounting software, Teams, Outlook, and other workplace applications.

Overall, Employee A does not need a high-end workstation. A standard business laptop with adequate RAM, an SSD, a suitable modern CPU, and reliable network connectivity should be sufficient for the employee's daily work.

## Employee B(Sales Employee)
Regularly uses;
- Teams
- CRM
- Outlook
- Browser applications
- Presentations
- Video calls

As a Sales Employee, the applications listed for regular use mean this employee would need a more capable workstation than Employee A. 

CPU: A modern processor with around 6 cores would be suitable. The CPU processes and executes instructions and provides the processing capacity needed to run multiple applications at the same time.

RAM: 16 GB would be suitable. Since the employee have Teams, CRM, Outlook, browser tabs and presentation software running together, sufficient RAM will help the applications operate smoothly.

Storage: A 512 GB SSD or larger would be suitable. An SSD provides fast storage for the operating system, applications and work files. It is also faster than an HDD when loading applications and accessing files.

Network Capability: Reliable Wi-Fi is particularly important because the employee frequently works remotely. Ethernet can also be used when a wired connection is available. A stable internet connection is important for Teams, CRM applications, and video calls.

Operating System: Windows 10/11 Pro would be suitable because it supports common business applications used by the employee.

Additional Requirements: A built-in or external webcam and microphone would be useful for video calls and remote meetings. Good Wi-Fi capability is also important for reliable remote work.

Overall, Employee B should receive a more capable workstation than Employee A because the employee regularly uses multiple applications, participates in video calls, and frequently works remotely.

## Employee C(Technical Analyst)
Uses;
- Multiple browser sessions
- virtual machines
- scripting tools
- large log files
- development tools

Employee C would require a significantly more capable workstation than Employees A and B because the role involves multiple browser sessions, virtual machines, scripting tools, large log files, and development tools. These activities can require substantial processing, memory, and storage resources.

CPU: A modern processor with 10 or more cores would be suitable. The additional processing capacity would help the employee run multiple applications and virtual machines while performing other tasks. When virtual machines are used, the hypervisor allocates virtual CPU resources to them while the host operating system still needs processing resources.

RAM: 32 GB or more would be recommended. Virtual machines require RAM from the host computer while the employee may also have development tools, browsers, scripting tools, and large log files open. Having more RAM allows these workloads to run without placing excessive memory pressure on the workstation.

Storage: A large SSD would be preferred for the operating system, applications, virtual machines, and frequently accessed files because SSDs provide faster access than HDDs. A combination of a 1 TB or larger SSD and additional HDD storage could also be used when the employee needs a large amount of storage for log files and other data.

Network Capability: The workstation should have reliable high-speed Wi-Fi and Gigabit Ethernet capability. A stable network is important when the employee is working with virtual machines, development resources, remote systems, and other network-based tools. The virtual machines can use different networking modes depending on the requirements of the technical laboratory.

Operating System: Windows 11 Pro would be suitable because it supports common development and technical tools and provides features useful for professional workstation management.

Additional Requirements: The workstation should have sufficient USB ports and support for external storage and other technical equipment. A good cooling system would also be important because the workstation may operate under heavier workloads for extended periods.

Overall, Employee C should be given a more capable workstation than Employees A and B because of the demanding nature of the work. The use of virtual machines, multiple browser sessions, scripting tools, development software, and large log files requires significantly more CPU, RAM, storage, and overall system capacity.
