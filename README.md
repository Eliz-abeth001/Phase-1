# Cybersecurity Phase One Project
# PROJECT TITILE: Meridian Technologies Infrastructure Stabilisation & Security Improvement Project
# PHASE ONE: IT Infrastructure Discovery & Stabilisation


## Phase One Overview
This repository contains the work completed for Phase One of my cybersecurity project.

The project focuses on developing practical foundational skills in computer systems, Operating System administration, Linux, virtualization, troubleshooting and cybersecurity lab setup.

## Phase One Objectives
The objectives of Phase One is to:

* Identify and document computer assets and their specifications.
* Make appropriate workstation recommendations for cybersecurity activities.
* Build and configure a virtual cybersecurity laboratory.
* Practice Windows administration.
* Establish a basic Linux environment and security baseline.
* Apply troubleshooting methods to identify and document technical problems.
* Document practical work using diagrams and screenshots.

## Project Activities
1. Asset Inventory

The asset inventory documents the available computer hardware and system information relevant to the project.

This includes information about the workstation and its available resources for carrying out cybersecurity activities.

2. Workstation Recommendations

This section evaluates the workstation requirements for the project and provides recommendations based on the available hardware and the practical activities to be performed.

3. Virtual Lab Build

This section documents the creation and configuration of the virtual laboratory.

VirtualBox was used to create and work with virtual machines for practical cybersecurity exercises.

The lab setup includes configuration and testing of virtual machine resources and networking.

4. Windows Administration

This section covers practical Windows administration activities.

The activities include working with Windows system tools, users and groups, system settings, networking information, and Event Viewer.

Command-line utilities were also used to examine and troubleshoot system and network information.

5. Linux Baseline

This section could not be completed because the Ubuntu Virtual Machine was not functioning reliably on my available system.

The work includes establishing a Linux environment and practicing fundamental command-line and system-management concepts using Ubuntu.

6. Troubleshooting Report

This section documents troubleshooting activities carried out during the project.

The troubleshooting process involved identifying problems, examining system and network information, testing possible causes, and documenting the results.

Tools Used

* Windows
* Task Manager
* Command Prompt
* Event Viewer
